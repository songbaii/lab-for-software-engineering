# 需求分析
## 需要用到的相关数据
> 逐阶段拓展需求
1. 登陆、注册界面
+ 用户名
+ 用户密码



2. 主页
根据用户推荐电影
请求：
+ 用户id
响应：
+ 推荐的电影
    + 电影名称
    + 电影分区
    + 电影简介/LLM生成的输出

```json
// 请求载体
{
    "user_id":"..."
}
// 响应
// 建议一次返回4个电影，方便前端排版
{
    "movies":[
        {
            "movie_id":"",
            "movie_name":"",
            "movie_type":"",
            "movie_content":""
        },
        // ...
    ]
}

```

用户评分
请求：
+ 用户id
+ 电影id
+ 用户评分
响应：
+ suceess
+ message

评分页面
+ 当前用户对该电影的打分

3. 冷启动
+ 登陆时，使用/api/like_query查询用户喜好，对偏好选择页面进行初始化
    + 如果偏好数组为空，则登陆后先展示偏好选择卡片
    + 如果偏好数组不为空，登陆后展示主页
+ 用户可以在主页打开偏好选择卡片更改偏好 /api/like
