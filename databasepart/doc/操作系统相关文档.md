# 操作系统相关文档

## 获取用户推荐

调用以下函数：
```python
def recommend_by_user_id(user_id: int, top_k=10, min_sim=0.01, recent_ratings_limit=None, random_factor=0.2):
"""
    获取用户推荐
    :param user_id: 用户ID
    :param top_k: 推荐数量
    :param min_sim: 最小相似度阈值
    :param recent_ratings_limit: 取最近多少条评分记录
    :param random_factor: 随机因子，0表示不随机，1表示完全随机
    :return: 推荐结果列表，格式如下：
    [
        {
            "movie_id": int(), # 电影ID
            "movie_name": str(), # 电影名称
            "release_year": int(), # 上映年份
            "avg_rating": float(), # 平均评分
            "vote_count": int(), # 评分次数
            "score": float() # 推荐分数(不用展示给用户)
        },
        ...
    ]
    注：该返回列表已经经过打乱
"""
```

## 数据库相关修改

1. 添加了item_similarities表：
   
```sql
item_similarities (
    movie_id INT NOT NULL, -- 电影ID
    similar_movie_id INT NOT NULL, -- 相似电影ID
    similarity DECIMAL(5,4) NOT NULL, -- 相似度
    FOREIGN KEY (movie_id) REFERENCES movie(movie_id) ON DELETE CASCADE,
    FOREIGN KEY (similar_movie_id) REFERENCES movie(movie_id) ON DELETE CASCADE,
    PRIMARY KEY (movie_id, similar_movie_id),
    INDEX idx_movie_id (movie_id),
    INDEX idx_similarity (similarity DESC)
);
```

此表无需实时更新。

2. 添加了movie_stats表：

```sql
movie_stats (
    movie_id INT PRIMARY KEY, -- 电影ID
    avg_rating DECIMAL(3,2) NOT NULL, -- 平均评分
    vote_count INT NOT NULL, -- 评分次数
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP, -- 更新时间
    FOREIGN KEY (movie_id) REFERENCES movie(movie_id) ON DELETE CASCADE,
    INDEX idx_vote_avg (vote_count, avg_rating)
);
```

当用户添加评分时需要更新movie_stats表中的数据。

3. 添加了user_favorite_genres表：

```sql
user_favorite_genres (
    user_id INT NOT NULL, -- 用户ID
    genre_id SMALLINT NOT NULL, -- 类别ID
    preference_score DECIMAL(3,2) DEFAULT 1.0, -- 偏好分数（可添加时之间设为1）
    FOREIGN KEY (user_id) REFERENCES user(user_id) ON DELETE CASCADE,
    FOREIGN KEY (genre_id) REFERENCES genre_table(genre_id) ON DELETE CASCADE,
    PRIMARY KEY (user_id, genre_id),
    INDEX idx_user_genre (user_id, genre_id)
);
```

当用户添加或修改喜好类别时需要更新user_favorite_genres表中的数据。

修改方法举例如下：

```sql
INSERT INTO user_favorite_genres (user_id, genre_id, preference_score) 
VALUES 
(114514, 1, 0.8),
(114514, 2, 0.8);
```
