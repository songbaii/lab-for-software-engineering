# 后端部分文档

## 登录部分

```
对应路由: '/api/login', methods=['POST']
接收JSON格式: {"user_id": "用户账号" number类型, "password": "密码" string类型}
返回JSON格式: {"success": "登录结果" boolean类型, "message": "提示信息" string类型}
```

## 注册部分

```
对应路由: '/api/register', methods=['POST']
接收JSON格式: {"user_name": "用户账号名" string类型, "password": "密码" string类型}
返回的JSON: {"success": "注册结果" boolean类型, "message": "提示信息" string类型, "user_id": "分配的用户账号" number类型}
```

## 评分部分

```
对应路由：'/api/judge'， methods = ['POST']
接受的JSON格式: {"user_id": "用户账号" number类型， "movie_id": "电影id" number类型， "rating": "用户评分" number类型}
返回的JSON格式: {"success": "评分结果" boolean类型， "message": "提示信息" string类型}
```

## 推荐部分

```
对应路由：'/api/recommend', methods = ['POST']
接受的JSON格式: {"user_id": "用户账号" number类型, "record_times": "先前已经推荐过的次数(第一次为0)" number类型}
返回的JSON格式: {"success": "推荐结果" boolean类型， "message": "提示信息" string类型, "recommend_movies": "推荐电影信息" 以数组的形式进行传输，每一个都具有"movie_id", "movie_name", "release_year", "avg_rating", "vote_count", "short_comment"属性}
```

## 修改密码部分

```
对应的路由：'/api/change_password', methods=['POST'], 功能：对用户的密码进行修改
接受的json格式:{"user_id": "用户账号" number类型, "new_password": "新密码" string类型}
返回的json格式:{"success": "修改结果" boolean类型， "message": "提示信息" string类型}
```

## 查询评分记录

```
对应的路由：'/api/get_record', methods=['POST']， 功能：对用户的评分记录进行查询。
接受的json格式:{"user_id": "用户账号" number类型}
返回的json格式:{"success": "修改结果" boolean类型， "message": "提示信息" string类型， ”records“： "评分记录" list类型，其中其中每一个元素是dict，包含了 movie_name, rating, timestamp, release属性}
```
